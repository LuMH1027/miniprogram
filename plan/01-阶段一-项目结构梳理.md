# 第一阶段：整理现有项目结构

## 具体开发内容
- 盘点点单主链路页面与路由。
- 盘点可复用组件和服务层接口。
- 输出可复用、需改造、可隐藏模块清单。

## 涉及页面或模块
- pages/home/home
- pages/goods/category/index
- pages/goods/details/index
- pages/cart/index
- pages/order/order-confirm/index
- pages/order/order-list/index
- services/order、services/cart、services/pay
- model/good、model/cart、model/order

## 需要修改的文件类型
- Markdown 文档
- 路由配置 JSON（仅记录，不改业务逻辑）

## 测试重点
- 浏览 -> 加车 -> 下单 -> 支付 -> 查单主链路可跑通。

## 注意事项
- 本阶段不做功能变更，只做结构基线和风险识别。
- 统一术语：商品=甜品饮品、购物车=点单车。
