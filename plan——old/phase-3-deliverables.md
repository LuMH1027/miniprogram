# 第三阶段交付物：菜品语义统一与字段映射

## 1. 菜品语义统一文案包

| 原文案 | 新文案 | 应用范围 |
| --- | --- | --- |
| 商品 | 菜品 | 列表、详情、订单确认、订单详情 |
| 商品列表 | 菜品列表 | `pages/goods/list/index.json` |
| 商品详情 | 菜品详情 | `pages/goods/details/index.json` |
| 购物车 | 点单车 | Tab、点单车页、异常提示 |
| 加入购物车 | 加入点单车 | 详情页底部栏、规格弹窗、Toast |
| 立即购买 | 立即下单 | 详情页底部栏、规格弹窗 |
| 购买数量 | 点单数量 | 规格弹窗 |
| 商品总额 | 菜品总额 | 订单确认、订单详情 |
| 收货地址 | 配送地址 | 我的、地址列表、订单确认 |
| 待发货 | 制作中 | 订单状态 |
| 确认收货 | 确认完成 | 订单操作 |

## 2. 字段映射说明

新增 `services/good/spu.js` 中的 `mapSpuToDish`，以显示层兼容方式提供菜品字段：

| 菜品字段 | 来源字段 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `dishName` | `dishName` / `name` | `未命名菜品` | 页面优先显示菜品名 |
| `name` | `name` / `dishName` | `未命名菜品` | 保持旧组件兼容 |
| `cover_image` | `cover_image` / `thumb` | 空字符串 | 兼容列表卡片图片 |
| `price` | `price` / `minSalePrice` | `0` | 兼容价格展示 |
| `monthSales` | `monthSales` / `soldNum` | `0` | 菜品卡片辅助信息 |
| `dishTags` | `dishTags` / `tags` | `[]` | 菜品标签 |

`listGood`、`getSpu`、`getAllSpuOfCate` 均透出映射后的数据，页面调用签名保持不变。

## 3. 点单车交互改造清单

| 交互 | 处理结果 |
| --- | --- |
| 空态 | “点单车是空的” |
| 删除确认 | “确认删除该菜品吗?” |
| 库存不足 | “部分菜品库存不足” |
| 规格重选 | “请重新选择菜品规格” |
| 加入成功 | “加入点单车成功” |
| 加入失败 | “加入点单车失败” |
| 去结算异常 | “获取点单车信息失败” / “清理点单车失败” |

## 4. Mock 数据

`services/cloudbaseMock/index.js` 已从商城样例替换为菜品样例：

- 招牌牛肉饭
- 香辣鸡腿堡套餐
- 番茄鸡蛋面
- 脆皮炸鸡翅

分类同步替换为主食、套餐、小吃、面食、盖饭、汉堡、炸物，规格同步替换为标准份、大份、套餐配可乐、套餐配薯条等点单语义。

## 5. 保留边界

本阶段没有重命名 `goods`、`spu`、`sku`、`cart` 等目录、字段或数据表名。它们仍作为技术实现名称存在，用户可见层面统一为菜品与点单车。
