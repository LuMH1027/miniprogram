# 第三阶段：调整 UI 为粉嫩情侣风

## 具体开发内容
- 建立全局情侣主题变量（颜色、圆角、阴影、间距）。
- 改造首页 Banner、商品卡片、按钮、输入框视觉。
- 增加轻量爱心和甜品元素点缀。

## 涉及页面或模块
- app.wxss
- style/theme.wxss
- style/global.wxss
- pages/home/home.wxss
- pages/goods/list/index.wxss
- pages/goods/details/index.wxss
- pages/cart/index.wxss
- pages/order/order-confirm/index.wxss
- components/goods-card/index.wxss

## 需要修改的文件类型
- WXSS（主题与样式）
- WXML（结构微调，装饰元素）

## 测试重点
- 多页面视觉一致性。
- 文本可读性与按钮点击区域。
- 真机颜色表现和弱网加载体验。

## 注意事项
- 装饰元素要少而精，不影响信息层级。
- 避免大面积深色和商业促销风。
