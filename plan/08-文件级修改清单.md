# 文件级修改清单（可直接开工）

## A. 先改配置与导航

### 1) app.json
修改点
- 精简页面入口，保留首页、分类、点单车、订单、我的。
- 弱化或移除优惠、活动、售后相关入口配置。

文件类型
- JSON

验收
